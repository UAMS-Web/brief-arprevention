Written against v1.0.1.

By the end of this page the theme will be active, with Genesis settings, a header menu, a footer menu, a logo and its colors in place.

It assumes the theme and the Genesis parent theme are installed (see [Installation (README)](https://github.com/UAMS-Web/brief-arprevention#readme)), on WordPress with PHP 8.2 or later and Genesis 3.0 or later.

## 1. Activate the theme

Go to **Appearance**, **Themes** and activate **Brief : AR Prevention**. Genesis applies the theme's starting settings when it is activated: a full-width layout, four posts per page, full-content archives with a 220-character limit, numeric post navigation and no breadcrumbs. The full list is under [Theme features](Theme-features.md#genesis-settings-on-activation).

## 2. Review the Genesis settings

Go to **Genesis**, **Theme Settings** and adjust what the site needs. The settings from step 1 are a starting point, not locked.

## 3. Assign the menus

Go to **Appearance**, **Menus** and assign a menu to each location:

- **Header Menu** is shown in the site header, beside the title or logo.
- **Footer Menu** is shown in the site footer, one level deep: submenu items are not shown.

On a screen narrower than 960 pixels the header menu collapses behind a menu button.

## 4. Add the logo

Go to **Appearance**, **Customize**, **Site Identity** and upload a logo. Set **Logo Width** to the widest the logo may be shown, in pixels; the default is 350 and the smallest accepted value is 100.

## 5. Set the colors

In the Customizer, open **Colors** and set **Text Color** and **Link Color**. The page preview shows the change before it is published. [Changing the colors and the logo](Changing-the-colors-and-the-logo.md) covers what each color reaches.

**Note:** the theme lets users with the Editor role open **Appearance**, **Menus**, and other screens that need the same capability, such as Genesis Theme Settings, and hides the Themes, Widgets and Customize pages from them. An administrator does steps 4 and 5.
